# CR-002 Requirements Specification — Specialized Agent Harness, 3-Stage Formal Verification, & Agent Constructor (Local Independent Version)

**Status:** Approved under **CR-002** (2026-10-25)  
**Edition:** Local Independent Version (`src/amca/` + `src/amca_agent/` + `app.py`)  
**Baseline Preserved:** `FR-01`–`FR-10`, `NFR-01`–`NFR-08` ([`01-requirements-specification.md`](01-requirements-specification.md)), and `CR-UI-01`–`CR-UI-09` ([`11-agent-web-extension-review.md`](11-agent-web-extension-review.md)).

## 1. Purpose and Scope

This document specifies the functional, formal-verification, agent-harness, hardware-safety, token-limit fallback, and anti-mocking requirements (`AC-01` through `AC-23`) for evolving AMCA into a **Specialized Agent Harness, Compositional 3-Stage Formal Verifier, and Standalone Python Agent Constructor**.

---
